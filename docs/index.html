PV string fault diagnosis from inverter MPPT voltage and current

Separating shorted bypass diodes, potential-induced degradation (PID) shunt loss, corroded MC4 / solder-joint series resistance, morning obstacle shading and uniform soiling from 15-minute inverter MPPT voltage and current alone, without a field I-V curve tracer. Verified on a 72-sub-string single-diode and reverse-bias breakdown model (Bishop 1988) across a 12-MPPT commercial string inverter (24 × 550 Wp half-cut mono-PERC modules per string, Vmp,STC = 1,003 V, Imp,STC = 13.16 A). Code and method: github.com/kwwaleszczynski-del/pv-string-iv-faults.

Working engineering material. SCADA MPPT telemetry isolates the faulty MPPT channel and separates step-voltage, ohmic-slope, low-irradiance shunt and current-loss signatures; physical confirmation on the roof or field still requires an electroluminescence (EL) camera, thermal inspection or a handheld I-V / insulation tester before replacing modules or connectors.
