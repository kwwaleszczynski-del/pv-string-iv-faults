PV string fault diagnosis from inverter MPPT voltage and current

Five string faults (shorted bypass diodes, extra series resistance, PID shunt loss, obstacle shading, soiling) are separated from 15-minute MPPT voltage and current, measured irradiance and the site coordinates. The data are synthetic: a 72-sub-string single-diode model with a reverse-bias (Bishop 1988) term generates every operating point, with string mismatch, cable resistance and sensor noise. Detector thresholds are fitted on 8 tuning inverters and every score below comes from 8 other, held-out inverters. Code and method: github.com/kwwaleszczynski-del/pv-string-iv-faults.

Working material on synthetic data, not a validated field tool. A SCADA signature points a field crew to the MPPT input; confirm with an I-V curve tracer, thermal or EL imaging and an insulation test before working on energized DC strings.

1. String I-V lab (model curves)

Curves come from the Python model on a grid of irradiance (cell temperature from 22 °C ambient). A shorted bypass diode removes one of 72 series sub-strings and extra series resistance subtracts I·ΔRs, so the page combines the healthy curve exactly: V(I) = (72 − nbd) · Vsub(I) − I · ΔRs. The PID, shading and soiling presets are separate model sweeps.
